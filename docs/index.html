호흡벨트를 가슴에 착용하고 전원을 켠 뒤 USB 또는 블루투스로 연결하세요.
아래 그래프에서 호흡에 따라 값이 움직이면 준비 완료입니다.

처음이신가요? 연결 전에 꼭 확인하세요
  1. PC의 Chrome 또는 Edge로 이 페이지를 새 탭에서 여세요. (Safari·아이폰 불가)
  2. Graphical Analysis 앱을 종료하세요. 주변 휴대폰·태블릿의 앱도 꺼 주세요. (벨트는 한 번에 한 곳에만 연결됩니다)
  3. PC의 블루투스를 켜세요. Windows 블루투스 설정에서 벨트를 따로 페어링하지 마세요.
  4. 벨트 전원을 켜면 표시등이 빨간색으로 깜빡입니다. 벨트를 PC 가까이(1~2m) 두세요.
  5. 블루투스로 연결 → 창에서 GDX-RB … 선택 → 페어링. 표시등이 초록색이 되고 아래 그래프가 숨에 따라 움직이면 성공입니다.
  6. 연결이 안 되면: 탭 닫기 → 벨트를 불이 꺼질 때까지 길게 눌러 끄고 5초 뒤 켜기 → 다시 열기. 그래도 안 되면 PC를 재시작하세요.
  7. 체험이 끝나면 탭을 닫고 벨트 전원을 꺼 주세요. 다음 사람이 바로 연결할 수 있습니다.
